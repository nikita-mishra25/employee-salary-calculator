# 👨‍💼 Employee Salary Calculator

A simple and responsive **Employee Salary Calculator** web application built using  
**HTML, CSS, and JavaScript**.

This project calculates **gross salary** and **net salary** based on basic salary,  
allowances, and deductions.

---

## 🚀 Technologies Used

- HTML5
- CSS3
- JavaScript

---

## ✨ Features

- Enter employee basic salary
- Calculate allowances (HRA, DA, etc.)
- Calculate deductions (PF, tax, etc.)
- Instant salary calculation
- Clean and user-friendly UI
- Responsive design

---

## 🧮 Salary Formula

- **Gross Salary** = Basic Salary + Allowances  
- **Net Salary** = Gross Salary − Deductions
